使用说明 ×
【核心玩法】
选分组 → 逐条看信号K线（信号日前 n / 后 n 个交易日）→ 标记分组归类 → 书签记录进度， 下次打开自动续读。
展示窗口前 n/后 n 可自定义（默认 200/20 全量），修改即时生效无需重新取数，拖动滑块可看全部数据。 【分组与标记】
· ＋建组 / 删组：删组会一并清除该组全部标记与书签；「全部」为内置分组不可删
· 标记分组：按信号（代码+信号日）勾选归属，一条信号可属多个分组，同股不同信号日可归不同组
· 选中分组后：信号下拉 / 序号 / 上一个下一个 / q/w 均按该组过滤；下拉选项尾部 [组名] 为已标记提示 【书签（阅读进度）】
· 每组一个书签，只前进不后退；「跳书签」回看书签信号，下拉中 ★ 即书签位置
· 进入分组视图自动定位到书签的下一条（未读首条，末尾循环），点「下一个」接着轮询 【复盘备注】
· 按信号（代码+信号日）记录复盘发现的点，与分组无关全局共享，任何分组下看到的是同一份备注
· 图表下方备注条自动显示当前信号备注全文，点备注条 /「写备注」按钮 / 快捷键 n 编辑
· 有备注的信号下拉尾部带 ✎，「写备注」按钮金实底深色提示；清空内容保存即删除备注 【快捷键】（跟随「快捷键」开关，焦点在输入框时无效）
q=上一个信号　w=下一个信号　c=复制代码　n=写备注　r=切换快捷键开关（关闭后仍可按 r 重新开启）
a=上一交易日　s=下一交易日　d=回到信号日（交易日光标越出可视窗口自动平移）
Esc=关闭弹窗/浮层（使用说明、标记分组、写备注；不受开关限制，输入框内也生效） 【图上标注】
金色竖线=信号日（「信号日线」开关）　金色虚线=信号日收盘价（「收盘价线」开关）
灰色点线=同股其它信号日　固定数据面板随十字光标刷新
