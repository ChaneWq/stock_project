# train_mode_day_k 训练交易功能设计

## 一、状态机

```
空闲态 ──开始训练──▶ 训练态 ──结束训练(须清仓)──▶ 空闲态
```

- 空闲态：可切换个股（上一个/下一个/下拉/序号跳转/查询），交易按钮全部禁用
- 训练态：锁定所有切换个股途径，仅可 Buy / Sell / Next day
- 结束训练：有持仓时点击提示「请先清仓」，清仓后才允许结束

## 二、按钮权限矩阵

| 操作 | 空闲态 | 训练态·空仓 | 训练态·持仓 |
|------|:---:|:---:|:---:|
| 上/下一个/下拉/序号/查询 | 可用 | 禁用 | 禁用 |
| 开始训练 | 可用 | — | — |
| 结束训练 | — | 可用 | 禁用(提示先清仓) |
| Buy | 禁用 | 可用(数据未到底) | 禁用(已全仓) |
| Sell | 禁用 | 禁用(无仓) | 可用 |
| Next day | 禁用 | 可用 | 可用 |

> 数据到底（信号日后20个交易日全部揭晓）后：Buy / Next day 禁用；
> 空仓则只能结束训练，持仓则 Sell（以最后揭晓日收盘价）后结束。

## 三、训练流程

```
空闲：选股 → 点「开始训练」
  → 揭晓进度重置到信号日（光标/面板锚定信号日），账户初始化（现金10万），
    锁定切换控件，交易按钮激活
训练中：
  → Buy：以「最新揭晓日收盘价」整手买入（100股整数倍），余款留现金
  → Sell：以「最新揭晓日收盘价」全部卖出
  → Next day：揭晓+1天，光标/面板自动对准新揭晓日，持仓市值随新收盘价刷新
结束训练：
  → 持仓中：提示「请先清仓」，不允许结束
  → 空仓：解锁切换，展示训练结果（交易明细+期末资产+收益率），
    图上买卖点标注保留供复盘
```

## 四、交易规则

- 初始资金：100,000 元
- **全局账户**：资金跨个股、跨训练会话连续沿用——切换个股不清零，
  「开始训练」不再重置 10 万而是沿用当前现金；仅「重置账户」按钮或刷新页面归零
- 训练会话：每次「开始训练」开启新会话，记录会话起始资金与本会话交易明细
- 买入：`shares = floor(现金 / (收盘价×100)) × 100`（整手），不足一手不成交
- 卖出：全部持仓一次性卖出
- 成交价：最新揭晓日收盘价（图中最后一根K线）
- 不计手续费、印花税（纯训练模拟）
- 总资产 = 现金 + 持仓股数 × 最新收盘价
- 收益率两层口径：
  - **累计收益率**（账户面板）= 总资产 / 初始资金 - 1，跨个股跨会话累计战绩
  - **会话收益率**（结果面板）= 期末资金 / 会话起始资金 - 1，本次训练该股成果
- 持仓跨个股不会发生：清仓约束保证空闲态必空仓，切股沿用的只有资金与交易记录

## 五、UI 改动

- 表单区新增：「开始训练/结束训练」开关按钮、「重置账户」按钮（仅空闲态可用，
  现金回 10 万并清空交易记录/结果面板/图上标注）、Buy（红）/ Sell（绿）按钮
- 账户面板常显（空闲态+训练态）：现金 / 持仓股数 / 总资产 / 累计收益率
  （交易与揭晓后实时刷新；切股沿用不清零）
- 结束训练后结果面板（会话口径）：起始资金→期末资金、会话收益率、
  本会话交易明细（代码/日期/方向/价格/股数/金额）
- 图上买卖点标注：Buy 红色 B（K线低点下方）、Sell 绿色 S（K线高点上方），
  仅落在已揭晓区间，不泄露未来；结束训练后保留，切换个股清空（标注属个股）
- 账户与交易状态存前端内存，刷新页面重置

## 六、快捷键

跟随「快捷键」开关，焦点在输入框时不响应：

`q`=上一个　`w`=下一个　`c`=复制代码　`d`=Next day　`b`=Buy　`s`=Sell

（b/s 仅训练态生效；Buy 内部校验空仓+数据未到底，Sell 校验持仓）

## 八、训练记录保留与持久化（改进设计）

### 个股训练历史（切股不丢）

```
HISTORY = { 个股代码: [ {ts, start, final, trades: [...]}, ... ] }   每次结束训练追加
```

- B/S 点不再独立存储，**从交易账本派生**：按当前个股过滤后，date 映射到已揭晓数据索引重建标注
- 切换个股再切回：B/S 点自动恢复（仅已揭晓范围内的点，未来点待 Next day 揭晓后出现，不泄露）
- 两档样式：当前会话=实色大标记；历史会话=半透明小标记（区分本轮与历史）
- 空闲态查看训练过的个股：结果面板显示「历史训练记录」——
  会话摘要表（时间/资金变化/收益率/笔数）+ 该股全部交易明细

### 持久化（本地 JSON 文件 train_history.json，不入 git）

| 接口 | 时机 | 作用 |
|------|------|------|
| `GET /api/state` | 页面加载 | 恢复全局账户（现金/账本）+ 个股训练历史，刷新页面不丢 |
| `POST /api/session` | 结束训练 | 追加该股会话记录 + 更新持久化现金/账本 |
| `POST /api/reset` | 重置账户 | 现金回 10 万，清空账本与全部历史（含文件） |

- 落盘时机：会话闭环时（结束训练/重置）；训练中 Buy/Sell 只改内存，
  中途刷新丢的是未结束的会话，数据自洽
- 保存失败仅提示不回滚（本地内存已生效，刷新后丢未落盘部分）

## 九、已训练个股：不可重复训练 + 数据全量开放

「已训练」判定 = 持久化历史中存在该 code（后端权威判定，前端无法绕过）。

| 行为 | 未训练个股 | 已训练个股 |
|------|-----------|-----------|
| 信号日后数据 | 后端裁剪，Next day 逐日揭晓 | **全量开放**（days_after 强制=20） |
| 开始训练 | 可用 | **禁用**（不可重复训练） |
| 下拉列表 | 普通显示 | 带 **✓已训练** 标记 |
| 图上 B/S 点 | 随揭晓逐步出现 | 全量显示 |
| 历史训练记录面板 | 无 | 显示（会话摘要+明细） |

- 后端 `/api/kline`：`trained = code 在 history 中存在`，为真时 days_after 强制 AFTER，
  payload 返回 `trained` 字段
- 防偷看机制不变：仅对未训练个股生效；用户改前端参数也无法提前看未训练个股
- 自洽性：训练态锁切股 → 训练中遇到的必然是未训练个股；
  落盘失败刷新后 HISTORY 恢复为空 → 不会锁死
- 「重置账户」清空全部历史 → 所有股恢复可训练（✓ 标记同步清除）
