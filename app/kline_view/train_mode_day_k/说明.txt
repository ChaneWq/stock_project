train_mode_day_k：日K训练模式（防偷看未来数据 + 训练交易）

沿用 signal_day_k 框架。读取 signals.csv（code,trade_date 信号日清单，本地维护不入 git），
展示信号日前 200 个交易日的日K线；初始只展示到信号日为止，
点「Next day」（快捷键 d）逐日揭晓信号日后的交易日（最多 20 天），
到达上限或数据末尾后按钮禁用并提示「已到最后可揭晓交易日」。

训练交易（设计见 设计方案.md）：
- 「开始训练」：揭晓进度重置到信号日，锁定所有切换个股途径
  （下拉/上一个/下一个/查询/序号），仅开放交易操作；
- 全局账户：资金跨个股、跨训练会话连续沿用，切换个股不清零，
  「开始训练」沿用当前现金（首次为10万）；「重置账户」按钮（仅空闲态）回到10万清空记录；
- Buy：以最新揭晓日收盘价整手买入（100股整数倍），余款留现金；已全仓或数据到底不可买；
- Sell：以最新揭晓日收盘价全部卖出；持仓市值随每日揭晓刷新；
- 「结束训练」：持仓中拒绝并提示先清仓；空仓结束后解锁切换，
  显示会话结果（起始→期末资金/会话收益率/本会话交易明细），
  图上买卖点标注保留供复盘（切股切回自动恢复，按交易账本派生）；
- 账户面板常显：现金/持仓/总资产/累计收益率（全局口径，相对初始10万，
  跨个股跨会话累计战绩）；交易不计手续费；
- 图上买卖点：Buy 红色 B（低点下方）、Sell 绿色 S（高点上方），仅落在已揭晓区间；
- 现金/账本/训练历史经 train_history.json 持久化（见下），刷新页面不丢。

训练记录保留与持久化：
- 个股训练历史按代码保存（每次结束训练追加一条会话记录），
  切换个股再切回：图上 B/S 点自动恢复（历史会话半透明小标记，当前会话实色大标记，
  仅显示已揭晓范围内的点），结果面板显示该股历史训练记录（会话摘要+交易明细）；
- 本地 JSON 文件 train_history.json 持久化（不入 git）：页面启动恢复现金/账本/历史，
  刷新页面不丢；结束训练/重置账户时落盘，训练中交易仅存内存（中途刷新丢未结束会话）；
- 「重置账户」（仅空闲态）= 现金回 10 万 + 清空全部账本与历史（含文件）。

成绩统计（「成绩统计」按钮开合的右侧侧面板，GET /api/stats 实时计算）：
- 面板形态：固定覆盖右侧表单区（480px 完全重合），K线常驻可见不被遮盖，
  表单临时被盖、关面板即恢复；再点按钮或面板内 × 关闭；每次打开重新拉取最新统计；
- 口径：全局账本 Buy→Sell 配对（会话必清仓），盈亏归属 Sell 平仓日，未平仓不计；
- 指标卡片：初始资金/当前现金/累计收益与收益率/交易笔数/胜率/盈亏比/
  平均持有/训练股票数/平均盈亏/平均亏损/平均盈利幅度/平均亏损幅度（单笔收益率口径，
  亏损为负）/最佳与最差单笔（面板内 2 列排布）；
- 按日盈亏可视化：当日平仓盈亏柱状图（红盈绿亏，左轴）+ 累计收益金色曲线（右轴），
  悬浮显示日期/当日盈亏/平仓笔数/累计；
- 每月盈亏可视化：当月盈亏幅度柱（红盈绿亏，左轴，基数为月初总资产）
  + 累计收益率金线（右轴），悬浮显示当月盈亏/平仓笔数/当月幅度/累计收益率；
- 交易个股回看表（一行一股，全部交易过的个股）：代码/笔数/胜负/胜率/累计盈亏/
  收益率（资金加权=合计盈亏÷合计买入金额）/平均持有 七列，点击表头排序（同列再点反向，
  箭头指示，默认累计盈亏降序），顶部代码搜索即时过滤，
  收益率 ≥±5% 底色高亮（红盈绿亏）；点击行跳转左侧K线回看该股（面板不关闭，
  可连续点下一只循环回看；同股多信号日取首笔买入日前最近的信号），当前回看个股金色描边；
- 每笔明细表（买卖日期价格/持有/盈亏/收益率），点行同样跳转该股K线；
- 训练态点行仅提示不跳转；面板打开时快捷键失效防误触；
- 无已完成交易时显示空态提示；重置账户后统计同步清空。

已训练判定（(code, 信号日) 维度，结束过一次训练即视为该信号已训练）：
- 同一股票的第二次信号不受第一次训练影响：第二次信号仍从 days_after=0 逐日揭晓，
  下拉无 ✓ 标记、可正常开始训练（旧逻辑按 code 判定会锁死并泄露第二次信号的未来数据）；
- 已训练信号：下拉列表带 ✓已训练 标记，「开始训练」禁用，不可重复训练；
- 切回该信号时信号日后 K 线数据全量开放（后端按持久化历史判定，不再裁剪），
  历史 B/S 点全量显示，历史训练记录面板照常显示；
- 旧数据兼容：train_history.json 中无 signal_date 字段的旧会话无法区分训练的是哪个信号，
  该股全部会话均为旧记录时保守回退 code 级判定（视为已训练防偷看），
  新旧混合时按新记录精确匹配；重置账户后全部恢复可训练。

防偷看设计（后端裁剪，前端拖动滑块/看请求都拿不到未来数据）：
- /api/kline 增加 days_after 参数，返回数据只到 信号日+days_after；
- 同股未来信号日的灰色弱标注一并过滤，不泄露未来信号位置；
- 预热只预取 days_after=0，不泄露未来；
- 切换信号（下拉/上一个/下一个/序号跳转/查询按钮）揭晓进度归零；
- 已移除「后 n」窗口输入框，后 n 仅由 Next day 按钮控制。

光标锚定（数据面板+图上可见十字线联动）：
- 初始/切换信号后光标（面板+十字线）锚定信号日；
- 点 Next day 揭晓后光标自动对准最新揭晓日，数据面板跟随展示该日数据；
- 鼠标移入图表十字线正常跟随，移出图表回到当前锚点。

表单侧栏按功能分区展示（惯例同 signal_day_k 工具栏分区）：信号浏览（信号下拉/上一个/
下一个/序号/查询/上次训练蓝描边）、训练操作（开始训练/Buy红/Sell绿/Next day绿/进度/
账户面板独立一行）、训练管理（重置账户红描边弱化防误触/成绩统计/使用说明）、
展示设置（展示前n/三个开关），区块浅灰底圆角+左上角标签纵向堆叠；
查询按钮 min-width 固定，查询/查询中两态等宽不推移同行控件。控件 id 与交互逻辑不变。

其余与 signal_day_k 一致：信号日金色标注（蜡烛金边+竖线贯穿+收盘价水平虚线；竖线宽 0.77，
「信号日线」开关控制竖线显示、「收盘价线」开关控制水平虚线，均即时启停不重渲染），
图例（K线/MA7/ZX短线趋势/ZX牛熊线）靠右显示，主图指标 MA7（红）、ZX短线趋势（白）、ZX牛熊线（黄），
固定数据面板随十字光标刷新，展示窗口前 n 修改即时生效无需重新取数，
当前信号渲染完成后后台全量预热清单所有信号（串行+500ms间隔温和限速），
键盘快捷键 q=上一个、w=下一个、c=复制当前代码、d=Next day、b=Buy、s=Sell、
z=开始/结束训练（「快捷键」开关可启停，默认开启；焦点在输入框或说明弹窗打开时不响应；
b/s 仅训练态生效）。

启动：run.bat，或 python -m app.kline_view.train_mode_day_k.web
