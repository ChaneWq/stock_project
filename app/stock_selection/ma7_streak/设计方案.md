# MA7线上连续爬升选股器（MA7 Streak）设计方案 v1

> 位置：`app/stock_selection/ma7_streak/`
> 日期：2026-08-27
> 状态：方案评审中（未开始编码）

---

## 1. 背景与目标

用户观察：002134 自 2026-08-04 起连续站上 MA7 日线，期间小阴小阳爬升，
2026-08-27 涨停兑现。

**目标**：筛选"股价连续 N 日运行在 MA7 上方、且以小阴小阳为主"的个股——
这类走势是主力控盘/筹码锁定的特征（没人砸盘也没人抢筹，量价温和），往往蓄势待发。

**核心输出**：个股当前 MA7 线上连续天数（streak）+ 小阴小阳质量指标 + 是否入选信号。

## 2. 案例复盘：002134 为什么典型

真实日线数据（`BasicBars().get_daily('002134', 60)`）：

| 日期 | 收盘 | 涨幅% | MA7 | 站上 | 形态角色 |
|------------|------|--------|-------|------|----------|
| 2026-08-03 | 18.49 | +0.43 | 19.20 | ✗ | 均线下方 |
| 2026-08-04 | 19.64 | **+6.22** | 19.16 | ✓ | **放量突破站上MA7（streak起点）** |
| 2026-08-05 | 20.46 | +4.18 | 19.16 | ✓ | 加速 |
| 2026-08-06 | 21.03 | +2.79 | 19.36 | ✓ | 中阳 |
| 2026-08-07 | 22.55 | +7.23 | 19.81 | ✓ | 大阳 |
| 2026-08-10 | 22.52 | -0.13 | 20.44 | ✓ | 小阴 |
| 2026-08-11 | 22.56 | +0.18 | 21.04 | ✓ | 小阳 |
| 2026-08-12 | 22.93 | +1.64 | 21.67 | ✓ | 小阳 |
| 2026-08-13 | 22.35 | -2.53 | 22.06 | ✓ | 小阴（**连续8天，streak=8**） |
| 2026-08-14 | 22.32 | -0.13 | 22.32 | ✗ | 边缘跌破（差0.003元），streak终止 |
| 08-17~08-26 | ~21 | 小幅震荡 | — | ✗ | 均线下方缩量整理9天 |
| 2026-08-27 | 22.63 | **+10.01** | 21.20 | ✓ | **涨停，形态兑现** |

**形态三段论**：
1. **突破站上**（08-04）：放量 +6.2% 收盘站上 MA7，streak 开始
2. **控盘爬升**（08-04 ~ 08-13）：连续 8 天收于 MA7 上方；后半程（08-10起）全为小阴小阳（|涨跌|≤3%），MA7 一路上行 —— 主力锁仓、筹码稳定的典型特征
3. **兑现**（08-27）：整理 9 天后涨停

**关键洞察**：
- streak 计数用**收盘价 > MA7** 的严格判定（08-14 差 0.003 元也算破位，避免模棱两可）
- streak 起点（突破日）通常是大阳，小阴小阳要求不应覆盖首日 —— 质量指标按"除首日外的天数"计算或用宽松比例
- 小阴小阳爬升期间 MA7 本身必须向上（死猫跳横盘不算）

## 3. 筛选逻辑设计

### 3.1 核心指标计算（逐股）

```
ma7[i]      = close.rolling(7).mean()
above[i]    = 模式判定（见下）
streak[i]   = 连续 above 的天数（当前值 = 从最新K线往回数）
```

**两种选股模式（mode 参数，自定义开启）**：

| 模式 | above 判定 | 语义 |
|------|-----------|------|
| `strict` 严格模式（默认） | `close > ma7` | 收盘价必须高于MA7，贴线跌破即断裂 |
| `near` 附近模式 | `(close - ma7) / ma7 >= -near_tolerance` | 收盘价在MA7上方，**或跌破幅度 ≤ 容差**（默认1%）——贴线小幅回踩不断裂，明显破位仍终止 |

002134 对照（容差1%）：

| 日期 | 偏离 | strict | near |
|------|------|--------|------|
| 08-13 | +1.33% | ✓ | ✓ |
| 08-14 | -0.01% | ✗ 断裂 | ✓ 贴线 |
| 08-18 | -0.63% | ✗ | ✓ 贴线 |
| 08-19 | -5.31% | ✗ | ✗ 明显破位终止 |

→ strict 模式 streak=8（08-04~08-13）；near 模式 streak=11（08-04~08-18）。

**streak 窗口内的质量指标**（窗口 = 从 streak 起点到最新）：

| 指标 | 定义 | 用途 |
|------|------|------|
| small_candle_ratio | 窗口内 \|pct\| ≤ small_pct 的天数占比（**剔除首日**，首日是突破大阳） | 控盘程度 |
| avg_abs_pct | 窗口内平均每日涨跌幅绝对值 | 波动率 |
| ma7_slope_pct | (最新ma7 − 窗口起点ma7) / 窗口起点ma7 | 趋势方向 |
| dev_pct | (close − ma7) / ma7 × 100 | 当前提离度（乖离过大风险） |
| max_dd_pct | 窗口内收盘价距窗口最高收盘的回撤 | 爬升稳定性 |

### 3.2 入选条件（全部满足）

| # | 条件 | 默认值 | 说明 |
|---|------|--------|------|
| 1 | streak_days ≥ min_streak_days | 5 | 核心：连续MA7线上天数 |
| 2 | small_candle_ratio ≥ min_small_ratio | 0.6 | 小阴小阳占比（剔除首日） |
| 3 | ma7_slope_pct > 0 | > 0 | MA7必须向上 |
| 4 | dev_pct ≤ max_dev_pct | 8% | 收盘价不远离MA7（防追高） |

### 3.3 002134 模拟验算

**strict 模式（以 2026-08-13 为基准日）**：

- streak_days = 8（08-04 ~ 08-13）✓ ≥5
- 剔除首日后窗口7天（08-05~08-13）：小阴小阳（|pct|≤3%）= 08-06/10/11/12/13 共 5 天，ratio = 5/7 ≈ **0.71** ✓ ≥0.6
- ma7_slope = (22.06−19.16)/19.16 ≈ **+15.1%** ✓ >0
- dev_pct = (22.35−22.06)/22.06 ≈ **+1.3%** ✓ ≤8%

**四项全过 → strict 模式下 002134 在 08-13 当天被选出**，14 天后（08-27）涨停兑现。

**near 模式（以 2026-08-18 为基准日，容差1%）**：

- streak_days = 11（08-04 ~ 08-18，08-14/08-18 贴线不断裂）✓ ≥5
- 剔除首日后窗口10天：小阴小阳 = 08-06/10/11/12/13/14/17/18 共 8 天，ratio = 8/10 = **0.80** ✓ ≥0.6
- ma7_slope = (22.53−19.16)/19.16 ≈ **+17.6%** ✓ >0
- dev_pct = (22.39−22.53)/22.53 ≈ **-0.6%** ✓ ≤8%

**四项全过 → near 模式下 002134 在 08-18 仍被选出**（涨停前 7 个交易日），容错了 08-14/08-18 两次贴线回踩。

> 验收标准（模糊形态核对，同 vp_score 约定）：
> ① 08-04 识别为 streak 起点；② strict：08-13 streak=8、08-14 断裂；
> ③ near：08-14/08-18 不断裂、streak=11、08-19 终止；
> ④ strict 基准日 08-13、near 基准日 08-18 均满足全部入选条件；⑤ 08-27 新 streak 重新起算。

## 4. 输出字段定义

逐股一行（单股模式输出逐日表 + 汇总，批量模式输出汇总表）：

| 字段 | 说明 |
|------|------|
| code / trade_date | 股票代码 / 基准日期 |
| close / ma7 | 最新收盘价 / MA7值 |
| streak_days | **连续MA7线上天数（核心）** |
| streak_start | streak 起始日 |
| small_candle_ratio | 小阴小阳占比（剔除首日） |
| avg_abs_pct | 平均日波动(%) |
| ma7_slope_pct | 窗口内MA7涨幅(%) |
| dev_pct | 收盘价对MA7偏离(%) |
| is_candidate | 是否入选（满足 3.2 全部条件） |

## 5. 目录结构与模块设计

```
app/stock_selection/
├── 说明.txt                  # 已有：目录用途说明
└── ma7_streak/               # 本选股器：MA7线上连续爬升
    ├── 设计方案.md            # 本文档
    ├── ma7_streak.py         # Ma7StreakSelector（计算+筛选）
    └── demo.py               # 002134 案例验证脚本
    （后续按需增加 scan.py 批量扫描 / 接入股票池）
```

**模块接口**：
- 类 `Ma7StreakSelector`（不继承 IndicatorBase——选股器输出汇总指标而非逐日指标列，
  但复用其输入验证思路；如需融入指标体系后续再评估）
- 构造参数含 `mode`（'strict' / 'near'）与 `near_tolerance`（附近模式容差，默认1%）
- `analyze(df)` → dict：单股汇总指标（streak/质量指标/is_candidate）
- `analyze_series(df)` → DataFrame：逐日 streak 序列（回看案例用，可复现任意历史日期的选股结果）
- `demo.py`：拉取 002134 真实数据 → 两种模式逐日streak对照表 → 基准日验算 → 模糊形态核对

**数据依赖**：`pystock_data.basic.bars.BasicBars().get_daily(code, n)`，n 需 ≥ 120
（MA7 + 最长streak + 余量）。

## 8. 已知局限与迭代方向（v2 候选）

1. **无量能维度**：v1 只看价，未验证"小阴小阳是否缩量"（缩量小阴小阳控盘更真）→ v2 加 volume/shrink 权重
2. **streak 起点性质不区分**：缓步站上（小阳爬上MA7）与放量突破（大阳站上）未区分，后者爆发力通常更强 → v2 加"首日突破强度"标签
3. **横盘贴线误选风险**：贴着MA7横走（slope≈0）靠条件3排除，但极缓上行仍可能入选 → v2 可加 slope 下限
4. **单周期**：仅MA7，未对照 MA20/MA60 多头排列 → v2 加均线系统共振加分
5. **无未来收益回测**：入选后 N 日胜率/收益未知 → 接入回测后用数据调参
