# 量价打分指标（VP Score）设计方案 v1

> 位置：`app/index_develop/vp_score/`
> 日期：2026-08-27
> 状态：方案评审中（未开始编码）

---

## 1. 背景与目标

用户观察：000592 在 2026-08-24 之后股价开始拉升，而拉升前的量价形态"特别好看"——
08-18 爆量上涨 4%+，随后连续缩量小跌，最后启动。

**目标**：对个股每个交易日的量价表现打分，量化"爆量后缩量回调蓄势"这类形态，
在启动前（而非启动后）给出高分预警。

**核心输出**：逐日评分表 + 关键事件（爆量信号 / 极度缩量 / 启动确认 / 形态失败）。

---

## 2. 案例复盘：000592 为什么"好看"

真实日线数据（`BasicBars().get_daily('000592')`）：

| 日期 | 收盘 | 涨幅% | vr5¹ | 量/0818量² | 形态角色 |
|------------|------|--------|------|-----------|----------|
| 2026-08-18 | 6.82 | **+4.12** | **3.74** | 100% | 爆量大阳：主力资金进场 |
| 2026-08-19 | 6.18 | -9.38 | 1.69 | 71% | 恐慌宣泄（量能开始收缩） |
| 2026-08-20 | 6.14 | -0.65 | 0.82 | 41% | 缩量小跌：抛压轻 |
| 2026-08-21 | 6.08 | -0.98 | **0.45** | **23%** | 极度缩量：抛压枯竭 |
| 2026-08-24 | 5.91 | -2.80 | 0.48 | 24% | 缩量回踩尾声 |
| 2026-08-25 | 6.18 | +4.57 | 0.66 | 34% | 放量反弹（量为前日1.42倍） |
| 2026-08-27 | 6.81 | **+10.02** | 2.66 | 78% | 涨停启动 |

> ¹ vr5 = 当日成交量 / 前5日平均成交量（不含当日）
> ² 量/0818量 = 当日成交量相对爆量日的收缩比

**形态三段论**：
1. **爆量信号**（08-18）：量能 3.7 倍于均量 + 涨 4%+，主力进场标志
2. **缩量回调**（08-19 ~ 08-24）：量能萎缩至爆量日的 23%~24%，跌幅收窄，无恐慌抛压 → 是"洗盘"而非"出货"
3. **启动确认**（08-25 / 08-27）：放量上涨，洗盘结束

**关键洞察**：回调期间跌幅不浅（-13%），单看价格不"好看"；好看的是**量能行为**——
爆量后量能一路枯竭。因此打分核心看"量能收缩质量"，价格回撤只轻惩罚，不设硬性破位终止。

## 3. 评分体系设计（两层）

单日好不好看（Layer 1）和形态好不好看（Layer 2）是两回事：
08-21 单日是"缩量小跌"（平淡），但在形态里它是"抛压枯竭"（关键加分日）。

### 3.1 Layer 1：单日量价分 day_score（-100 ~ +100）

每天独立评价，两个分量相加后截断：

**① 涨跌方向分**：`pct * 8`，上限 +40，下限 -40

**② 量价配合分**（按"涨/跌 × 量比"查表）：

| 情形 | vr5 区间 | 得分 | 含义 |
|------|---------|------|------|
| 上涨 | ≥ 2.5 | +40 | 爆量上涨，主力进场 |
| 上涨 | 1.2 ~ 2.5 | +30 | 温和放量上涨 |
| 上涨 | < 0.7 | +20 | 缩量上涨，惜售锁仓 |
| 上涨 | 0.7 ~ 1.2 | +15 | 常量上涨 |
| 下跌 | ≥ 2.0 | -40 | 放量大跌，出货嫌疑 |
| 下跌 | 1.2 ~ 2.0 | -25 | 带量下跌 |
| 下跌 | 0.5 ~ 1.2 | -5 | 常量下跌 |
| 下跌 | < 0.5 | **+15** | **极度缩量下跌，抛压衰竭**（本形态的灵魂） |

> 注：下跌缩量给正分，是本指标与普通打分的最大差异——回调缩量是好事。

### 3.2 Layer 2：形态累计分 pattern_score（核心输出，状态机）

```
[SEARCHING 寻找信号] --爆量大阳--> [PULLBACK 回调蓄势] --放量上涨--> [CONFIRMED 启动确认]
                                        |  \失败/超时
                                        +--> [EXPIRED 形态结束] --重新寻找-->
```

**① 信号日触发（SEARCHING → PULLBACK），初始 60 分**

满足任一：
- vr5 ≥ 2.0 且 涨幅 ≥ 3%
- vr5 ≥ 3.0 且 涨幅 ≥ 1%（低位首日启动容忍）

记录信号日成交量 `vol_s`、收盘价 `close_s`。

**② 回调蓄势期（PULLBACK），逐日四项加减：**

| 分项 | 条件 | 得分 | 说明 |
|------|------|------|------|
| 缩量分（shrink = 当日量/vol_s） | shrink ≤ 0.3 | +10 | 极度缩量，洗盘充分 |
| | 0.3 < shrink ≤ 0.5 | +7 | 明显缩量 |
| | 0.5 < shrink ≤ 0.8 | +4 | 温和缩量 |
| | shrink > 1.0 | -10 | 再爆量（结合涨跌判断） |
| 跌幅分 | -1 ≤ pct < 0 | +8 | 小跌，最理想 |
| | -3 ≤ pct < -1 | +3 | 中跌 |
| | -6 ≤ pct < -3 | -5 | 大跌 |
| | pct < -6 | -15 | 暴跌，破坏形态 |
| | 0 ≤ pct < 3 | +5 | 横盘企稳 |
| 收敛分 | \|pct\| < 前一日\|pct\| | +3 | 跌幅收敛 |
| 深度分（dd = close/close_s - 1） | dd > -5% | +8 | 浅回调，强势 |
| | -10% < dd ≤ -5% | +3 | |
| | -15% < dd ≤ -10% | -3 | |
| | dd ≤ -15% | -8 | 回调过深 |

**③ 启动确认（PULLBACK → CONFIRMED），+25 分**

回调期内出现：涨幅 ≥ 3% 且 当日量 ≥ 前一日量 × 1.3

**④ 形态终止（PULLBACK → EXPIRED）**

- **失败**：单日 涨幅 ≤ -5% 且 当日量 ≥ 0.8 × vol_s（放量暴跌 = 出货），score 清零
- **过期**：回调期超过 10 个交易日未启动，score 逐日衰减 -15 至 0

### 3.3 000592 模拟评分（手工验算）

| 日期 | 事件 | 缩量 | 跌幅 | 收敛 | 深度 | pattern_score | day_score |
|------|------|------|------|------|------|---------------|-----------|
| 08-18 | **爆量信号** | - | - | - | - | **60** | +73 |
| 08-19 | 恐慌宣泄 | +4 | -15 | - | +3 | 52 | -65 |
| 08-20 | 缩量小跌 | +7 | +8 | +3 | +3 | 73 | -10 |
| 08-21 | **极度缩量** | +10 | +8 | - | -3 | 88 | +7 |
| 08-24 | 回踩尾声 | +10 | +3 | - | -3 | **98** | -7 |
| 08-25 | **启动确认** | +25 | | | | **123** | +57 |
| 08-27 | 涨停加速 | | | | | 133 | +80 |

**结果符合预期**：形态分在缩量回调期间持续走高（60→52→73→88→98），
启动前夕（08-24）达到峰值区间，08-25 确认。——分数曲线就是"好看程度"曲线。

## 4. 输出字段定义

每日一行，DataFrame 输出（按时间升序）：

| 字段 | 说明 |
|------|------|
| trade_date / close / pct / vr5 / volume | 基础行情 |
| day_score | 单日量价分（-100~100） |
| state | SEARCHING / SIGNAL(信号日) / PULLBACK / CONFIRMED / EXPIRED |
| shrink_ratio | 当日量 / 信号日量（无信号为空） |
| pattern_score | 形态累计分（无信号为 0） |
| event | 爆量信号 / 极度缩量 / 启动确认 / 形态失败 / 形态过期 |

**下游信号约定**（供扫描器/选股使用）：
- `state == PULLBACK && pattern_score >= 80` → 蓄势预警（关注池）
- `state == CONFIRMED` → 启动信号（触发池）

## 5. 目录结构与模块设计

```
app/index_develop/
├── 说明.txt                  # 已有：目录用途说明
└── vp_score/                 # 本指标：量价打分
    ├── 设计方案.md            # 本文档
    ├── vp_score.py           # VPScoreIndicator（继承 pystock_data 的 IndicatorBase）
    └── demo.py               # 000592 案例验证脚本
    （后续按需增加 backtest.py / scanner.py）
```

**模块接口**：
- 类 `VPScoreIndicator(IndicatorBase)`，`required_fields = ['open','high','low','close','volume']`
- `calculate(df)`：输入日线 DataFrame（内部兼容倒序/正序），输出附加评分列
- `demo.py`：拉取 000592 真实数据 → 打分 → 打印评分表 → 与 3.3 手工验算值核对
- 所有阈值参数以类默认参数形式集中定义（对齐项目 config 集中管理约定）

**数据依赖**：`pystock_data.basic.bars.BasicBars().get_daily(code, n)`，不手工构造数据。

## 8. 已知局限与迭代方向（v2 候选）

1. **单信号短视**：仅跟踪最近一个爆量信号，多轮爆量蓄势（N 字结构）暂不处理
2. **无位置感知**：未结合股价所处阶段（低位首板 vs 高位补涨），高位爆量风险不同 → v2 可加"相对前期高点的位置分"
3. **量能基准单一**：vr5 对连日爆量后会失真（本方案已用"相对信号日量"缓解）→ v2 可用分位数量能（当日量在过去 60 日的分位）
4. **连续缩量奖励**：连续 N 日缩量可给阶梯奖励，鼓励更完整刻画
5. **大盘/板块过滤**：环境极端弱势时信号胜率低 → v2 结合指数状态降权
